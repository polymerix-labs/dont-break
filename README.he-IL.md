![Rule Studio: תארו מה אסור שישבר, צפו בגרף מוצא אותו ובוחן את ההגנה](https://raw.githubusercontent.com/polymerix-labs/dont-break/main/docs/assets/screenshot.png)

סוכני בינה מלאכותית שולחים קוד מהר. אף אחד לא שולח איתו אמון. כל צוות שמשתמש ב-Cursor, Claude או בוטים של CI חולק את אותו הפחד הבלתי מדובר: היום שבו תיקון מהיר ישבור בשקט את הדבר היחיד שאסור לו להישבר לעולם.

`dont-break` הופך את הפחד הזה לחוזה:

1. **אמרו זאת במילים פשוטות.** "אף אחד לא אמור להיות מסוגל לשבור את חישוב החשבוניות, אפילו לא בעקיפין." בלי נתיבי קבצים, בלי קוד.
2. **צפו בו נמצא.** dont-break קורא את המפה החיה של בסיס הקוד שלכם ומאיר כל מקום שנושא את הלוגיקה הזו, כולל נתיבים ששכחתם שקיימים.
3. **צפו בו מותקף.** הוא כותב כלל הגנה, ואז מריץ מחדש שינויי קוד נגדו כדי להוכיח שההגנה באמת מחזיקה מעמד. הרצה יבשה: שום דבר בקוד שלכם לא נגע.
4. **הפעילו אותו.** מכאן ואילך, כל עריכה של סוכן נבדקת מול הכלל לפני שהיא נכנסת לתוקף. הסוכן שלכם שומע "זה מסוכן יותר ממה שנראה" במקום שתגלו זאת בייצור.

```text
אתם:     "שנו את שם PokemonService.fetchAll"
סוכן:    → get_dependents(PokemonService.fetchAll)   "23 נקודות קריאה ב-4 מודולים"
         → get_impact(files: [...])                  "רדיוס 3, משפיע על ui/, cache/, api/"
         → get_do_not_touch()                        "PokemonService הוא אזור סכנה: fan-in 23, יציבות 31"
סוכן:    "זה מסוכן יותר ממה שנראה. הנה 23 המקומות שישברו,
          ותוכנית בטוחה יותר ב-2 שלבים."
```

השיחה הזו קורית אוטומטית ברגע שאתם מחוברים. בלי הנדסת פרומפטים: כישור הסוכן מלמד אותו.

## התקנה

דורש **Python 3.9+** ו-**Node.js** (npm). מחלץ הגרף מתקין את עצמו בהפעלה הראשונה.

```bash
pip install dont-break
dont-break --wake
```

זה פותח ממשק מקומי בכתובת `http://127.0.0.1:4040`, בשפה שלכם (32 זמינות). התחברו, בחרו תיקיית פרויקט, ומפת הקוד שלכם נבנית מעצמה: גרף תלת-ממדי חי של כל מודול, קריאה ותלות, עם אזורי ההגנה שלכם מוארים מעל.

עבודה אחת שגורמת למיזוג להיכשל כאשר שינוי פוגע באזור מוגן או בצומת שביר, מבוסס על גרף תלויות אמיתי, לא על תחושת בטן.<br>
→ [GitHub Actions](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/github-actions.md) · [GitLab CI](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/gitlab-ci.md) · [hook של pre-commit](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/pre-commit.md)

**"אני רק רוצה לתשאל את בסיס הקוד שלי"**<br>
`dbq dependents <id> | jq`: מה נשבר אם אני משנה את זה? המאגר שלכם הופך למסד נתונים שניתן לתשאל.<br>
→ [מתכוני Shell + jq](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/shell.md)

**"אני בונה סוכן משלי"**<br>
אותם 11 כלים, זמינים כהגדרות TypeScript מוקלדות או מפרט OpenAPI 3.1 שנוצר.<br>
→ [LangChain / OpenAPI / סוכנים מותאמים](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/langchain.md)

| `get_dependencies` | "במה הקוד הזה תלוי?" |
| `find_path` | "למה שינוי ב-A משפיע על B?" |
| `get_arch_status` | "כמה זהירות עליי לנקוט במאגר הזה?" |

## חדר הבקרה

- **Rule Studio**: תארו מה אסור שישבר, צפו בגרף מוצא אותו, בחנו את ההגנה בזמן אמת לפני ההפעלה
- **Check**: סימולטור טרום-עריכה: בחרו זרעים, קבלו פסק דין ok/warn/block, הנפישו את הנתיב המדויק שהשבירה הייתה נוקטת
- **Overview**: פסק דין במשפט אחד, מדדי יציבות וניווטיות בינה מלאכותית, הפעולות המובילות שיחזקו את הארכיטקטורה שלכם
- **Graph**: סצנת ה-Nebula התלת-ממדית, אזורים מוגנים ונתיבי עדות מוארים כשכבות-על
- **Agents**: חברו את Cursor, Claude או CI בלחיצה אחת, עם הדגמת ניסיון-לשבור חיה

מוכוון מקלדת: `cmd+K` פותח את לוח הפקודות.

## חברו את הסוכן שלכם תוך 30 שניות

1. פתחו את אפליקציית dont-break ← **Agents**.
2. התחברו, קשרו תיקייה לפרויקט, לחצו על **Connect Cursor**: לחיצה אחת יוצרת אסימון מוגבל לפרויקט וממלאת את `mcp.json`.
3. הדביקו אותו ב-Cursor (או בלקוח ה-MCP שלכם).
4. לחצו על **Install agent skill**: זה כותב את פרוטוקול השינוי הבטוח לתוך `AGENTS.md` של המאגר שלכם, כך שסוכנים ישתמשו בכלים בלי שיצטרכו להיאמר.
