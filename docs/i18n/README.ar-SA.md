![Rule Studio: صف ما يجب ألا ينكسر أبدا، وشاهد الرسم البياني يجده ويختبر الحماية](https://raw.githubusercontent.com/polymerix-labs/dont-break/main/docs/assets/screenshot.png)

الوكلاء الذكيون يشحنون الكود بسرعة. لا أحد يشحن الثقة معه. كل فريق يستخدم Cursor أو Claude أو بوتات CI يشارك نفس المخاوف غير المعلنة: اليوم الذي يكسر فيه إصلاح سريع بصمت الشيء الوحيد الذي لم يكن يجب أن ينكسر أبدا.

`dont-break` يحول هذا الخوف إلى عقد:

1. **قله بكلمات بسيطة.** "لا أحد يجب أن يستطيع كسر حساب الفواتير، حتى بشكل غير مباشر." بدون مسارات ملفات، بدون كود.
2. **شاهده يُكتشف.** dont-break يقرأ الخريطة الحية لقاعدة الكود لديك ويضيء كل مكان يحمل هذا المنطق، بما في ذلك المسارات التي نسيت وجودها.
3. **شاهده يُهاجم.** يكتب قاعدة حماية، ثم يعيد تشغيل تغييرات الكود ضدها لإثبات أن الحماية تصمد فعلا. تشغيل تجريبي: لا شيء في الكود الخاص بك يُلمس.
4. **فعّلها.** من تلك اللحظة، كل تعديل من الوكيل يُفحص مقابل القاعدة قبل أن يُطبق. يُخبر وكيلك "هذا أخطر مما يبدو" بدلا من أن تكتشف ذلك في الإنتاج.

```text
أنت:      "أعد تسمية PokemonService.fetchAll"
الوكيل:   → get_dependents(PokemonService.fetchAll)   "23 موقع استدعاء عبر 4 وحدات"
          → get_impact(files: [...])                  "نصف قطر 3، يلمس ui/, cache/, api/"
          → get_do_not_touch()                        "PokemonService منطقة خطرة: fan-in 23، استقرار 31"
الوكيل:   "هذا أخطر مما يبدو. إليك الـ23 مكانا التي ستنكسر،
           وخطة أكثر أمانا من خطوتين."
```

هذا الحوار يحدث تلقائيا بمجرد الاتصال. بدون هندسة موجهات: مهارة الوكيل تعلّمه ذلك.

## اللغات والقدرات

اللغات التي يرسمها dont-break، وما تستطيع كل واحدة فعله فعلاً، على **[dont-break.com/language-support](https://dont-break.com/language-support)**.

## التثبيت

يتطلب **Python 3.9+** و **Node.js** (npm). مستخرج الرسم البياني يثبت نفسه عند أول تشغيل.

```bash
pip install dont-break
dont-break --wake
```

يفتح هذا واجهة محلية على `http://127.0.0.1:4040`، بلغتك (32 لغة متاحة). سجّل الدخول، اختر مجلد مشروع، وخريطة الكود الخاص بك تُبنى من تلقائها: رسم بياني ثلاثي الأبعاد حي لكل وحدة واستدعاء واعتماد، مع مناطقك المحمية مضاءة فوقه.

## اختر معركتك

**"وكيلي يستمر في كسر أشياء لم يفتحها أبدا"**<br>
اربط dont-break بـ Cursor أو Claude Desktop. وكيلك يفحص التأثير والمناطق الخطرة قبل التعديل، وليس بعده.<br>
→ [الإعداد في Cursor / Claude (دقيقتان)](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/cursor.md)

**"أريد أن تحجب CI الكوارث، لا أن تجادل حول الأسلوب"**<br>
مهمة واحدة تفشل الدمج عندما يمس تغيير منطقة محمية أو عقدة هشة، مبنية على الرسم البياني الحقيقي للاعتمادات، لا على الحدس.<br>
→ [GitHub Actions](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/github-actions.md) · [GitLab CI](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/gitlab-ci.md) · [خطاف pre-commit](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/pre-commit.md)

**"أريد فقط استجواب قاعدة الكود الخاصة بي"**<br>
`dbq dependents <id> | jq`: من ينكسر إذا غيرت هذا؟ يصبح مستودعك قاعدة بيانات قابلة للاستعلام.<br>
→ [وصفات Shell + jq](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/shell.md)

**"أنا أبني وكيلي الخاص"**<br>
نفس الأدوات الـ11، مكشوفة كتعريفات TypeScript مكتوبة أو مواصفة OpenAPI 3.1 مولّدة.<br>
→ [LangChain / OpenAPI / وكلاء مخصصون](https://github.com/polymerix-labs/dont-break/blob/main/docs/agents/langchain.md)

## الأدوات الـ11 التي يحصل عليها وكيلك

| الأداة | السؤال الذي تحسمه |
|------|----------------------|
| `find_symbol` | "أي عقدة هذا الاسم / الملف؟" (نقطة الدخول) |
| `get_dependents` | "من ينكسر إذا غيرت هذا؟" |
| `get_impact` | "ما نصف قطر تأثير هذه التعديلات؟" |
| `get_do_not_touch` | "ما الذي يجب أن أرفض لمسه دون سؤال؟" |
| `get_dependencies` | "على ماذا يعتمد هذا الكود؟" |
| `find_path` | "لماذا يؤثر تغيير A على B؟" |
| `get_arch_status` | "بأي حذر يجب أن أعمل في هذا المستودع؟" |
| `check_change` | "هل ينتهك هذا التعديل قاعدة فريق؟" |
| `propose_rule` | "سجّل تحذيرا الآن، أو حجبا ينتظر موافقة إنسان" |
| `pause_own_rule` | "أوقف تقييم قاعدة أنشأها رمز هذا الوكيل" |
| `append_rule_reason` | "أضف مبررا واحدا، لا تعدّل أو تحذف أبدا" |

أدوات الاستعلام للقراءة فقط، تحليل من جانب الخادم، استجابات محدودة: آمنة للاستدعاء دائما. أدوات القواعد الثلاث تكتب قواعد الفريق تحت قيود صارمة: لا يمكنها تفعيل حجب، أو إيقاف قاعدة شخص آخر، أو إعادة كتابة الأسباب.

## غرفة التحكم

- **Rule Studio**: صف ما يجب ألا ينكسر أبدا، شاهد الرسم البياني يجده، اختبر الحماية حية قبل تفعيلها
- **Check**: محاكي ما قبل التعديل: اختر بذورا، احصل على حكم ok/warn/block، حرّك المسار الدقيق الذي سيسلكه الكسر
- **Overview**: حكم في جملة واحدة، مؤشرات الاستقرار وقابلية التنقل بالذكاء الاصطناعي، أهم الإجراءات التي ستقوي بنيتك
- **Graph**: مشهد Nebula ثلاثي الأبعاد، المناطق المحمية والمسارات الشاهدة مضاءة كطبقات
- **Agents**: اربط Cursor أو Claude أو CI بنقرة واحدة، مع عرض حي لمحاولة الكسر

يعمل بالكامل عبر لوحة المفاتيح: `cmd+K` يفتح لوحة الأوامر.

## اربط وكيلك في 30 ثانية

1. افتح تطبيق dont-break ← **Agents**.
2. سجّل الدخول، اربط المجلد بمشروع، انقر **Connect Cursor**: نقرة واحدة تصدر رمزا مخصصا للمشروع وتملأ `mcp.json`.
3. الصقه في Cursor (أو عميل MCP الخاص بك).
4. انقر **Install agent skill**: يكتب بروتوكول التغيير الآمن في `AGENTS.md` الخاص بمستودعك حتى تستخدم الوكلاء الأدوات دون أن يُقال لها.
