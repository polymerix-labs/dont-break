# dontbreak

This is an alias package. It installs no code of its own — it depends on
[`dont-break`](https://pypi.org/project/dont-break/), the real package,
reserved under this name so a typo doesn't land on someone else's project.

```bash
pip install dontbreak   # pulls in dont-break
dont-break --wake
```

See [dont-break on PyPI](https://pypi.org/project/dont-break/) or
[the source](https://github.com/polymerix-labs/dont-break) for everything else.
