![Rule Studio: hech qachon buzilmasligi kerak bo'lgan narsani tasvirlang, grafning uni topishi va himoyani sinovdan o'tkazishini kuzating](https://raw.githubusercontent.com/polymerix-labs/dont-break/main/docs/assets/screenshot.png)

AI agentlar kodni tezda yetkazib beradi. Hech kim u bilan birga ishonchni yetkazib bermaydi. Cursor, Claude yoki CI botlaridan foydalanadigan har bir jamoa bir xil aytilmagan qo'rquvni baham ko'radi: tezkor tuzatish hech qachon buzilmasligi kerak bo'lgan yagona narsani jimgina buzib qo'yadigan kun.

`dont-break` bu qo'rquvni shartnomaga aylantiradi:

1. **Buni oddiy so'zlar bilan ayting.** "Hech kim hisob-faktura hisob-kitobini buza olmasligi kerak, hatto bilvosita ham." Fayl yo'llari yo'q, kod yo'q.
2. **Uning topilishini kuzating.** dont-break kod bazangizning tirik xaritasini o'qiydi va u mantiqni tashiydigan har bir joyni, mavjudligini unutgan yo'llaringiz bilan birga, yoritadi.
3. **Unga hujum qilinishini kuzating.** U himoya qoidasini yozadi, keyin himoya haqiqatan ham ushlab turishini isbotlash uchun kod o'zgarishlarini unga qarshi qayta o'ynatadi. Quruq sinov: kodingizda hech narsaga tegilmaydi.
4. **Uni faollashtiring.** O'shandan boshlab, har bir agent tahriri kuchga kirishidan oldin qoidaga qarshi tekshiriladi. Agentingiz buni ishlab chiqarishda bilib olishingiz o'rniga "bu ko'ringanidan xavfliroq" deb eshitadi.

```text
Siz:     "PokemonService.fetchAll nomini o'zgartir"
Agent:   → get_dependents(PokemonService.fetchAll)   "4 modulda 23 ta chaqiruv nuqtasi"
         → get_impact(files: [...])                  "radius 3, ui/, cache/, api/ ga ta'sir qiladi"
         → get_do_not_touch()                        "PokemonService xavfli hudud: fan-in 23, barqarorlik 31"
Agent:   "Bu ko'ringanidan xavfliroq. Mana buziladigan 23 ta joy,
          va 2 bosqichli xavfsizroq reja."
```

Bu suhbat ulanganingizdan so'ng avtomatik ravishda sodir bo'ladi. Prompt muhandisligi yo'q: agent ko'nikmasi buni o'rgatadi.

## O'rnatish

**Python 3.9+** va **Node.js** (npm) talab qilinadi. Graf ekstraktori birinchi ishga tushirishda o'zini o'zi o'rnatadi.

```bash
pip install dont-break
dont-break --wake
```

Bu `http://127.0.0.1:4040` manzilida, o'z tilingizda (32 ta mavjud) mahalliy interfeysni ochadi. Tizimga kiring, loyiha papkasini tanlang, va kodingiz xaritasi o'z-o'zidan quriladi: har bir modul, chaqiruv va bog'liqlikning tirik 3D grafi, ustida yoritilgan himoyalangan zonalaringiz bilan.

## Agentingiz oladigan 11 ta vosita

| Vosita | U javob beradigan savol |
|------|----------------------|
| `find_symbol` | "Bu nom / fayl qaysi tugun?" (kirish nuqtasi) |
| `get_dependents` | "Buni o'zgartirsam nima buziladi?" |
| `get_impact` | "Bu o'zgarishlarning ta'sir radiusi qancha?" |
| `get_do_not_touch` | "So'ramasdan nimaga tegishdan bosh tortishim kerak?" |
| `get_dependencies` | "Bu kod nimaga bog'liq?" |
| `find_path` | "Nega A dagi o'zgarish B ga ta'sir qiladi?" |
| `get_arch_status` | "Bu repo'da qanchalik ehtiyotkorlik bilan ishlashim kerak?" |
| `check_change` | "Bu o'zgarish jamoa qoidasini buzadimi?" |
| `propose_rule` | "Hozir ogohlantirishni yozib olish, yoki inson tasdig'i uchun bloklash" |
| `pause_own_rule` | "Ushbu agent tokeni yaratgan qoidani to'xtatib turish" |
| `append_rule_reason` | "Bitta asoslashni qo'shish, hech qachon tahrirlamaslik yoki o'chirmaslik" |

So'rov vositalari faqat o'qish uchun, server tomonidagi tahlil, cheklangan javoblar: har doim chaqirish xavfsiz. Uchta qoida vositasi qat'iy chegaralar ostida jamoa qoidalarini yozadi: ular bloklashni faollashtira olmaydi, boshqa birovning qoidasini to'xtatib qo'ya olmaydi yoki sabablarni qayta yoza olmaydi.

## Boshqaruv xonasi

- **Rule Studio**: hech qachon buzilmasligi kerak bo'lgan narsani tasvirlang, grafning uni topishini kuzating, faollashtirishdan oldin himoyani jonli sinab ko'ring
- **Check**: tahrirlashdan oldingi simulyator: urug'larni tanlang, ok/warn/block hukmini oling, buzilish izlaydigan aniq yo'lni animatsiya qiling
- **Overview**: bir jumlada hukm, barqarorlik va AI-navigatsiya ko'rsatkichlari, arxitekturangizni mustahkamlaydigan eng muhim harakatlar
- **Graph**: 3D Nebula sahnasi, himoyalangan zonalar va guvoh yo'llar qoplama sifatida yoritilgan
- **Agents**: Cursor, Claude yoki CI-ni bir marta bosish bilan ulang, jonli try-to-break namoyishi bilan

Klaviatura birinchi: `cmd+K` buyruqlar palitrasini ochadi.

## Agentingizni 30 soniyada ulang

1. dont-break ilovasini oching → **Agents**.
2. Tizimga kiring, papkani loyihaga bog'lang, **Connect Cursor**ni bosing: bitta bosish loyihaga xos tokenni yaratadi va `mcp.json`ni to'ldiradi.
3. Uni Cursor-ga (yoki MCP mijozingizga) joylashtiring.
4. **Install agent skill**ni bosing: bu xavfsiz o'zgartirish protokolini repo'ingizning `AGENTS.md` fayliga yozadi, shunda agentlar aytilmasdan vositalardan foydalanadi.
